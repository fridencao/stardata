## StarData access for managed pipelines

In addition to standard connectors, StarData also manages data pipelines for customers or sets up orchestration for moving data from object stores/data warehouses into StarData's managed database service. StarData's dedicated data engineering services help build out everything from basic orchestration to complete data enrichment and custom data pipelines.

To provide access for the StarData team, your team can grant read access: 

- [Amazon s3](/developers/other/granting/aws-s3-bucket)
- [GCS](/developers/other/granting/gcs-bucket)
- [Google BigQuery](/developers/other/granting/google-bigquery)
- [Microsoft Azure Storage](/developers/other/granting/azure-storage-container)

For more information on how StarData can help, please contact our team at [contact@rilldata.com](mailto:contact@rilldata.com).

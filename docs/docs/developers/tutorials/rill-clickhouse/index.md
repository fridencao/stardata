In this tutorial, we will discuss how to use ClickHouse as the default OLAP database with StarData to visualize your ClickHouse tables in as little as a few clicks. 

The overall steps of the tutorial are:
1. Launch StarData Developer
2. Connect to your ClickHouse server whether it is locally run or via ClickHouse Cloud
3. Create a metrics view based on a table in ClickHouse
4. Create an explore dashboard via Generative AI
5. Deploy the dashboard to StarData Cloud, and share to colleagues

Once completed, you will have a basic understanding of how to use StarData Developer with ClickHouse and can customize the StarData Developer project to create further metrics views based on ClickHouse tables and create more dashboards. 

### Let's get started!
